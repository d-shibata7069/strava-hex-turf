## Strava OAuth スコープ別 データ取得・利用・保持ポリシー

審査提出用に、現在リクエストしているスコープ単位でデータの取り扱いを整理します。

| Scope | 取得データ | 利用目的 | 保持 / 削除方針 |
|------|-----------|---------|----------------|
| `read` | アスリートの公開プロフィール（表示名、プロフィール画像、Strava athlete ID） | ログイン中ユーザー識別、グループ表示名・アイコン表示、ランキング表示 | Supabase に保存。ユーザーがアプリ設定からアカウント削除を実行した時点で関連プロフィール情報を削除。 |
| `activity:read` | 公開アクティビティのメタデータ・GPS（距離、時刻、緯度経度系列） | H3 タイルの奪取/防衛判定、スコア計算、Activity Log 表示 | ゲーム進行に必要な範囲で Supabase に保存。ユーザーのアカウント削除時に当該ユーザーの活動由来データ（タイル履歴・ログ）を削除。 |
| `activity:read_all` | 非公開アクティビティを含むアクティビティデータ | 現在要求している。Webhook で受け取るアクティビティには非公開のものも含まれ、それらも陣取り判定の処理対象になるため、このスコープで取得できる必要がある。あわせて、ユーザーが `privacy_zone`（自宅周辺等）を設定している場合は、そのゾーン内の H3 セルを領地化対象から除外する（`backend-api/src/utils/privacy-zone.ts`、Webhook 処理に実装済み）。 | ゲーム進行に必要な範囲で Supabase に保存（プライバシーゾーン内のセルは保存しない）。ユーザーのアカウント削除時に当該ユーザーの活動由来データ（タイル履歴・ログ）を削除。 |
